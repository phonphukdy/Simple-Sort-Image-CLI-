# sortimg — โปรแกรมคัดแยกรูปภาพใน terminal

## ติดตั้ง (ทำครั้งเดียว)

รองรับ **macOS / Linux / WSL** (ต้องมี `bash` และ `python3`)

1. ดาวน์โหลดไฟล์ทั้งหมด (`sortimg.py`, `install.sh`, `requirements.txt`) มาไว้ที่โฟลเดอร์เดียวกัน เช่น `~/Downloads/sortimg/`
2. เปิด terminal แล้ว cd ไปที่โฟลเดอร์นั้น:
   ```bash
   cd ~/Downloads/sortimg
   ```
3. ติดตั้ง Python dependencies:
   ```bash
   pip3 install -r requirements.txt
   ```
4. (แนะนำ) ติดตั้งตัวแสดงรูปสีสวยใน terminal — เลือกอย่างใดอย่างหนึ่ง:
   ```bash
   # macOS
   brew install chafa

   # Ubuntu / Debian
   sudo apt install chafa
   ```
   ถ้าไม่ติดตั้งอันนี้ โปรแกรมจะ fallback ไปใช้ Pillow แสดง preview แบบหยาบแทน (ยังใช้งานได้ปกติ)
5. รัน installer:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
   สคริปต์นี้จะ:
   - คัดลอก `sortimg.py` ไปไว้ถาวรที่ `~/.sortimg/sortimg.py`
   - สร้างคำสั่ง `sortimg` เชื่อมไปยังสคริปต์นั้น ใส่ไว้ที่ `~/.local/bin/sortimg`
   - เช็ค PATH และ dependency ให้ พร้อมบอกวิธีแก้ถ้ายังไม่ครบ
6. ถ้า installer แจ้งว่า `~/.local/bin` ยังไม่อยู่ใน PATH ให้เพิ่มบรรทัดนี้ในไฟล์ `~/.bashrc` หรือ `~/.zshrc`:
   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   ```
   แล้วรัน `source ~/.bashrc` (หรือ `source ~/.zshrc`) หรือเปิด terminal ใหม่

## วิธีใช้งาน

จากนี้ไป ไม่ต้องยุ่งกับไฟล์ script อีกเลย แค่:

```bash
cd /โฟลเดอร์ที่มีรูปที่จะคัดแยก
sortimg
```

โปรแกรมจะสแกนรูปในโฟลเดอร์ปัจจุบัน (เฉพาะ top-level, นามสกุล jpg/jpeg/png/gif/webp/bmp) แล้วแสดงทีละรูปพร้อมรายการหมวดหมู่และคำสั่งที่ใช้ได้

### คำสั่งระหว่างใช้งาน (พิมพ์แล้ว Enter)

| คำสั่ง | ความหมาย |
|---|---|
| `d` | ลบรูปนี้ (ย้ายไป Trash ระบบตอนออกโปรแกรม) |
| `o` | ย้ายไปหมวด `other` (จะสร้างเป็น `99_other` อัตโนมัติ) |
| `n -m "ชื่อ"` | สร้างหมวดใหม่ แล้วย้ายรูปนี้เข้าไปทันที |
| `n` | สร้างหมวดใหม่ (จะถามชื่อภายหลัง) |
| `00`, `01`, ... | ย้ายรูปนี้เข้าหมวดหมู่ตามเลขนั้น |
| `undo` | ย้อน action ล่าสุด (กดซ้ำได้หลายครั้ง) |
| `q` | ออกจากโปรแกรม |

### หมายเหตุการทำงาน

- หมวดหมู่คือโฟลเดอร์ชื่อ `NN_ชื่อ` (เลข 00-98) เช่น `00_memories`, `01_screenshots` — โปรแกรมจะสแกนหาโฟลเดอร์เหล่านี้จากชื่อจริงทุกครั้งที่เปิด ไม่มีไฟล์ config แยก
- เลขหมวดใหม่จะเติมช่องว่างที่หายไปก่อนเสมอ (เช่น มี 00, 02 อยู่ → หมวดใหม่จะได้ 01)
- ชื่อหมวดห้ามซ้ำกับที่มีอยู่แล้ว ถ้าซ้ำจะแจ้งเตือนและให้พิมพ์คำสั่งใหม่ (ไม่เคลียร์หน้าจอ)
- ถ้าย้ายรูปเข้าหมวดแล้วชื่อไฟล์ซ้ำกับที่มีอยู่ในนั้น จะถามให้เลือกลบทิ้งหรือย้ายไป `other` แทน
- การลบ (`d`) จะพักไฟล์ไว้ในโฟลเดอร์ซ่อน `.sortimg_trash` ก่อน เพื่อให้ `undo` ทำงานได้ทันที แล้วจะย้ายเข้า Trash ระบบจริงตอนออกโปรแกรม (`q` หรือคัดครบทุกรูป) — กู้คืนได้จาก Trash ของเครื่องตามปกติ
